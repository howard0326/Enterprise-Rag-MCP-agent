# 订单状态与业务字段说明

## 1. 订单状态机

| 状态 | 含义 | 可否取消 | 可否退款 |
| --- | --- | --- | --- |
| `pending` | 已下单未支付 | 可 | 无需退款 |
| `paid` | 已支付待发货 | 可 | 可全额退 |
| `shipped` | 已发货未签收 | 不可，需拒收 | 拒收后自动全额退 |
| `delivered` | 已签收 | 不可 | 需走退货申请 |
| `refunded` | 已退款 | 不可 | 不可重复退 |
| `cancelled` | 已取消 | 不可 | 不可 |

## 2. 核心字段

- `order_id`：订单号，格式 `ORD-###`，全局唯一；
- `customer_id`：客户 ID，格式 `CUST-####`，一个客户可有多个订单；
- `amount`：订单实付金额（元），不含运费；
- `created_at`：下单时间（订单归属日期以此字段为准）；
- `delivered_at`：签收时间，退货期限从该时间起算；
- `items`：商品明细数组，每项含 `sku` / `name` / `qty` / `price`。

## 3. 常见排查路径

**"订单 A 能不能退？"**
1. 取订单状态；
2. 若 `delivered`，比较 `delivered_at` 与当前日期的间隔天数；
3. 对照退货政策第 2 条的期限与第 5 条的排除情形；
4. 给出结论时必须同时给出依据条款与下一步操作。

**"客户说没收到货。"**
1. 查订单状态是否为 `shipped` 或 `delivered`；
2. `delivered` 但客户否认签收 → 建 `high` 工单，附物流单号；
3. `shipped` 超过 7 天未更新物流 → 建 `high` 工单核对承运商。

## 4. 数据口径约定

- 所有金额单位为人民币元，保留两位小数；
- 统计"当月订单量"时剔除 `cancelled` 状态；
- 退款率 = `refunded` 订单数 / 当期 `paid` 及之后状态订单总数。
